# Tracey KQ – Next.js Fashion Brand

## Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS** – green palette utility classes
- **Framer Motion** – hero fade-ins, staggered cards, hover effects
- **Zustand** – cart + wishlist state

## Pages
| Route | Description |
|---|---|
| `/` | Home — hero banner, featured products, categories |
| `/shop` | Shop — filter grid, search |
| `/shop/[id]` | Product detail |
| `/lookbook` | Editorial lookbook grid |
| `/atelier` | Bespoke consultation |
| `/cart` | Cart + checkout |
| `/profile` | Profile + measurements |

## Color Palette
- `forest` `#1E3D1A` — primary dark background
- `olive` `#2A4E1F` — card surfaces
- `deep-olive` `#3A5C2D` — hover / active
- `accent` `#C8E96B` — primary CTA / highlights
- `cream` `#F5F3EE` — light card backgrounds
- `off-white` `#FAFAF7` — lightest surface
